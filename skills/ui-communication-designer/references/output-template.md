# Full Review Output Template

Use this shape for a multi-screen critique, redesign handoff, or explicit scored review. It is not required for a compact or copy-only response. Omit a field only when it is clearly outside scope.

## 1. Task Summary

- User:
- Primary goal:
- Platform:
- Success criteria:
- Evidence supplied:
- Assumptions:

## 2. What the User Cares About Most Right Now

List three to five questions in the user's language.

## 3. Human-to-Human Explanation

Explain the task naturally in three to eight sentences.

## 4. Recommended Task Flow

| Step | User decision | System response | Extra explanation | Commit point | Feedback/recovery |
|---|---|---|---|---|---|

Label the primary flow and each important exception or recovery path.

## 5. Screen or Section Recommendations

For each screen or section:

- Purpose:
- Focal point:
- Primary action:
- Secondary actions:
- Content or controls to remove/add:
- Interaction and feedback:
- Rationale:

## 6. Microcopy Rewrite

For each in-scope item, show `Original`, `Rewrite`, and `Why`:

- title or main instruction
- CTA
- helper text
- error
- warning or confirmation, only if needed

## 7. Priority Fix List

Group High, Medium, and Low items. Each item states the problem, change, and expected improvement.

## 8. Five-Second Test

Write three to five questions that test purpose, next action, outcome, choice, or trust.

## 9. Rubric

State evidence coverage and confidence. Use `references/rubric.md`. Mark unsupported dimensions `not assessed`; calculate `/24` only when all 12 dimensions are supported.
