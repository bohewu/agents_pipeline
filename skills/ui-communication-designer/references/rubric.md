# UI Communication Review Rubric

Score a dimension only when the supplied artifact or observed evidence supports it:

- `0`: clearly problematic
- `1`: usable but unstable
- `2`: clear, stable, and predictable
- `not assessed`: insufficient evidence

Dimensions:

1. **Value clarity** — the value or outcome is apparent before system mechanics.
2. **Task clarity** — the user knows what to do now.
3. **Discoverability** — the starting point and main command are findable.
4. **Understandability** — language avoids internal terms and unnecessary abbreviation.
5. **Affordance** — controls communicate how they can be used.
6. **Predictability** — the result and any commit point are clear before action.
7. **Efficiency** — the flow avoids unnecessary setup, repetition, and questions.
8. **Feedback** — responses are timely, specific, and actionable.
9. **Trust** — cost, risk, data use, and consequences are transparent.
10. **Forgiveness** — mistakes are preventable or recoverable and input is preserved.
11. **Non-annoyance** — interruption, repetition, and attention capture are restrained.
12. **Scanability** — focal point, eye path, and important content are clear.

When all dimensions are scored:

- `0–11`: redesign the flow or information architecture
- `12–17`: fix major structural issues; copy alone is insufficient
- `18–21`: structure is usable but needs targeted fixes
- `22–24`: focus on refinement

Never present this heuristic as user-research evidence. State confidence and coverage alongside the result.
